# تطبيق تعلم الكلمات للأطفال

تطبيق تعليمي تفاعلي شامل مصمم لمساعدة الأطفال على تعلم القراءة والكتابة باللغتين العربية والإنجليزية من خلال الألعاب التفاعلية والأنشطة الممتعة. 

🆕 **الآن مع نظام دفع متكامل يدعم البوابات المصرية والعالمية!**

## المميزات الرئيسية

### 🎮 الألعاب التعليمية
- **مطابقة الكلمات**: ربط الكلمات بالصور المناسبة
- **بناء الجمل**: تكوين جمل صحيحة من الكلمات
- **النطق**: تعلم النطق الصحيح للكلمات
- **الإملاء**: كتابة الكلمات بشكل صحيح
- **الاستماع**: التعرف على الكلمات من خلال الصوت

### 👥 أنواع المستخدمين
- **الأطفال**: واجهة مبسطة وألعاب تفاعلية (يحتاج ولي أمر)
- **أولياء الأمور**: إدارة حتى 4 أطفال، متابعة التقدم، الاشتراك مع المعلمين
- **المعلمون**: إدارة الفصول، إنشاء أنشطة مخصصة، تتبع الأرباح

### 💰 نظام الاشتراكات والدفع
- **اشتراك شهري**: 50 ريال سعودي (30 يوم)
- **اشتراك نصف سنوي**: 240 ريال سعودي (180 يوم) - **وفر 20%!**
- **حد أقصى**: 4 أطفال لكل ولي أمر، 4 طلاب لكل اشتراك معلم

### 🏦 بوابات الدفع المدعومة

#### 🇪🇬 البوابات المصرية:
- **فوري (Fawry)**: ادفع من أي منفذ فوري في مصر
- **فودافون كاش**: محفظة فودافون الرقمية
- **WE كاش**: محفظة WE الإلكترونية  
- **أورانج كاش**: محفظة أورانج للدفع
- **اتصالات كاش**: محفظة اتصالات الرقمية
- **مدى**: بطاقات مدى السعودية
- **التحويل البنكي**: البنوك المصرية والسعودية

#### 🌍 البوابات العالمية:
- **Stripe**: بطاقات ائتمان وخصم عالمية (Visa, MasterCard, Amex)
- **PayPal**: محفظة PayPal الرقمية
- **Apple Pay**: للـ iOS (iPhone/iPad)
- **Google Pay**: للـ Android
- **Samsung Pay**: لهواتف Samsung

### 🌟 المميزات التقنية
- **دعم اللغتين**: العربية والإنجليزية
- **تصميم متجاوب**: يعمل على جميع أحجام الشاشات
- **صوت عالي الجودة**: نطق واضح للكلمات
- **رسوم متحركة**: تأثيرات بصرية جذابة
- **حفظ التقدم**: تتبع إنجازات الطفل
- **وضع عدم الاتصال**: العمل بدون إنترنت

## التقنيات المستخدمة

### Frontend
- **Flutter**: إطار العمل الرئيسي
- **Riverpod**: إدارة الحالة
- **GetX**: التنقل والإدارة
- **ScreenUtil**: التصميم المتجاوب

### Backend & Database
- **SQLite**: قاعدة البيانات المحلية
- **Firebase**: المصادقة والتخزين السحابي
- **Dio & Retrofit**: التواصل مع الخادم

### Audio & Animation
- **Flutter TTS**: تحويل النص إلى كلام
- **AudioPlayers**: تشغيل الأصوات
- **Lottie**: الرسوم المتحركة
- **Animate Do**: تأثيرات الحركة

### UI/UX
- **Material Design**: تصميم متسق
- **Custom Widgets**: مكونات قابلة لإعادة الاستخدام
- **Shimmer**: تأثيرات التحميل
- **Confetti**: تأثيرات الاحتفال

## التثبيت والتشغيل

### المتطلبات
- Flutter SDK (3.9.2 أو أحدث)
- Dart SDK
- Android Studio / VS Code
- Firebase Project

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone https://github.com/your-repo/game_children_learning_words.git
cd game_children_learning_words
```

2. **تثبيت التبعيات**
```bash
flutter pub get
```

3. **إعداد Firebase**
- إنشاء مشروع Firebase جديد
- إضافة ملفات التكوين للأندرويد و iOS
- تفعيل Authentication و Firestore

4. **توليد الملفات**
```bash
flutter packages pub run build_runner build
```

5. **تشغيل التطبيق**
```bash
flutter run
```
